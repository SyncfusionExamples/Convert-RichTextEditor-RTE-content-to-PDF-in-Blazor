# Convert Rich Text Editor content to PDF

A Blazor sample demonstrating how to convert Rich Text Editor HTML content to a downloadable PDF.

## Project Overview

This sample shows how to capture HTML content from the Blazor Rich Text Editor and convert it into a PDF on the server or client (as the sample demonstrates). It includes instructions to build and run the project locally so you can test export and download workflows.

## Prerequisites

- .NET 8.0 SDK
- Visual Studio 2022+ or VS Code
- Syncfusion license (if required for project packages)

## Setup & Running Step

Installation

```bash
git clone https://github.com/SyncfusionExamples/Convert-RichTextEditor-RTE-content-to-PDF-in-Blazor.git
cd Convert-RichTextEditor-RTE-content-to-PDF-in-Blazor
```

Restore NuGet packages

```bash
dotnet restore
```

Run the application

```bash
dotnet run
```

## Usage

Open the sample in your browser, enter or paste content into the Rich Text Editor, then use the export to PDF feature. The sample demonstrates converting the editor HTML to a PDF and triggering a download.

## Troubleshooting

- Ensure NuGet packages are restored and the project builds before running.
- If export fails, check browser console and server logs for errors and confirm any required licenses are configured.
